# Development Guide

## Setup

```bash
# Clone repository
git clone <repo-url>

# Install dependencies
npm install  # or appropriate command for your stack

# Run development server
npm run dev
```

## Project Structure

```
src/          - Source code
tests/        - Test files
docs/         - Documentation
config/       - Configuration files
.agent-os/    - Agent OS specs and tasks
```

## Development Workflow

1. Create feature branch
2. Implement feature
3. Add tests
4. Update documentation
5. Create pull request

## Testing

```bash
npm test
```

## Code Style

Follow standard conventions for JavaScript/TypeScript.
